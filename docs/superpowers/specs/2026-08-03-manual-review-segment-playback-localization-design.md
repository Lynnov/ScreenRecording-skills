# 人工录制审核片段播放与中文化设计

> 日期：2026-08-03
>
> 状态：已确认，待实现

## 目标

审核窗口点击左侧片段后，中间播放器使用现有 `preview.mp4` 跳到该片段在 `preview-timeline.json` 中的起点，自动播放，并在终点循环。无需生成额外片段视频。

## 交互

- 初次进入时选中第一个片段并定位到其起点，不强制自动播放。
- 用户点击片段后立即定位、自动播放，并只在所选片段的 `startsAtMs` 至 `endsAtMs` 区间循环。
- 切换片段时更新选中状态、播放区间和审核表单。
- 时间轴缺少目标片段时显示中文错误，不静默播放整条视频。

## 中文显示

底层枚举值和 JSON 协议保持不变，只翻译用户可见文字：

- `Segment` → `片段`
- `approved` → `已通过`
- `pickup-required` → `需要补录`
- `rejected` → `已拒绝`
- `keep` → `保留`
- `compress` → `压缩等待`
- `original` / `pickup` → `原始录像` / `补录素材`
- `available` / `failed` / `superseded` → `可用` / `失败` / `已替换`

## 验证

- 定向测试覆盖中文文案、片段选择、时间轴定位、自动播放和区间循环。
- 运行 `npm run build:manual`。
- 重启真实 Electron 审核窗口，人工验证三个片段均能独立播放。
