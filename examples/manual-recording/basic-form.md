# 人工录制基础表单示例

## 目标

录制一个网页登录并填写基础表单的人工演示流程，用于验证 Agent guide 交接、人工 Action 指引和后续剪辑链路。

## 录制者准备

1. 打开示例业务系统登录页。
2. 手动登录测试账号。
3. 确认页面显示“基础信息表单”。

## 操作步骤

1. 在“客户名称”输入框填写“Pacdora 示例客户”。
2. 在“联系人”输入框填写“测试联系人”。
3. 在“业务类型”下拉框选择“试用咨询”。
4. 点击“保存”。
5. 等待页面出现“保存成功”。

## 验收结果

- 页面保留在表单详情页。
- 能看到“保存成功”。
- 能看到客户名称“Pacdora 示例客户”。
